# Alpha Session Scheduling Plan

Review's first scheduled instance is due exactly two days after a skill's real completion instant (`docs/review-foundation.md`). Session C must not be scheduled sooner, and must never be manufactured sooner by editing clocks or data for a real learner (`docs/alpha-session-c.md`) — the two-day gap is a fixed, honest constraint on the calendar, not a testing inconvenience to engineer around.

| Day | Activity |
|---|---|
| Day 0 | Recruitment and consent (`docs/alpha-recruitment-and-consent.md`) complete for the first cohort; disposable-account checklist (`docs/alpha-disposable-accounts.md`) fully complete; entry criteria for Session A (and, for any learner proceeding to B that day, Session B) re-checked live against `STEM_FORGE_ALPHA_READINESS.md` §6. |
| Day 1 | Session A (`docs/alpha-session-a.md`) for the full cohort; Session B (`docs/alpha-session-b.md`) immediately after, same day, for participants proceeding to it — this is what starts each learner's two-day Review clock on whichever skill they complete. |
| Day 2 | No learner sessions. Facilitator batches Day 1 findings per the severity rubric (`STEM_FORGE_ALPHA_READINESS.md` §5) and confirms production health is still green before Day 3. |
| Day 3+ (≥2 full days after each learner's Day 1 completion) | Session C (`docs/alpha-session-c.md`) for each learner, individually scheduled against their own real completion timestamp — not a single fixed date for the whole cohort, since learners will complete a skill at slightly different points in Day 1. |
| Day 3–5 | Remaining cohort members who haven't yet completed Session A/B run their Day 1 equivalent, offsetting their own Session C by the same +2-day rule. |
| End of window | Final evidence review, severity batching, and `docs/alpha-go-no-go-record.md` completed only once every recruited learner's applicable sessions are done or explicitly marked incomplete. |

A realistic window for 5–10 learners run this way is roughly 5–7 calendar days from first recruitment to final decision, dominated by the mandatory Review gap rather than facilitator availability.
